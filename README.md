# Aeria's Trial RPG

Welcome to **Aeria's Trial**, a compact text-based RPG built for the CCTA
codebase. You take on the role of Aeria, a brave adventurer tasked with
defeating a gauntlet of foes to bring peace back to the realm.

## Features

* Turn-based combat with three tactical options: attack, defend, and use a
  potion.
* Four unique enemy encounters that increase in difficulty.
* Simple status HUD to keep track of health and remaining potions.

## Getting Started

1. Ensure you have Python 3.8 or newer installed.
2. From the repository root, run the game with:

   ```bash
   python3 game.py
   ```

3. Follow the prompts in the terminal to guide Aeria through her trial.
