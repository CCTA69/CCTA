3D Roguelike Arena

A fast-paced, browser-based 3D action roguelike built with Three.js and Cannon.js.

Overview

Survive endless waves of zombies in a confined arena. Start with nothing but your fists, gain XP from kills, and level up to unlock powerful skills and masteries. Every run is unique as you choose from random upgrades to build your perfect zombie-slaying machine.

Key Features

Action Combat: Responsive WASD movement and mouse-aimed attacks. Switch between fast Fists and a heavy-hitting Sword.

Roguelike Progression: Earn XP to level up. Each level grants a choice of 3 random skills to add to your arsenal.

Deep Skill System: 6 unique active skills including Dash, Fireball, and Ice Nova.

Mastery Upgrades: Every 5 levels, skills evolve with game-changing new effects (e.g., Fireball becomes a lingering Inferno).

Physics-Based Gameplay: Knock zombies back with powerful attacks and watch them fly.

Controls

W, A, S, D: Move

Mouse: Look / Aim

Space: Attack

1, 2: Switch Weapon (Fist / Sword)

Q, E, R, F: Use Skills

Technologies Used

Three.js: For 3D rendering, models, and particles.

Cannon.js: For physics simulation and collision detection.

HTML5 / JavaScript: Core game logic and UI.

How to Play

Simply open index.html in any modern web browser. No installation required.
